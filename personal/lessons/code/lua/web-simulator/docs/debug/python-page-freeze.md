# Debug Session: python-page-freeze

Status: OPEN

## Symptom

- Python-скрипт с бесконечным циклом в веб-симуляторе вешает страницу.

## Initial Hypotheses

1. Цикл `while True` в Pyodide не отдаёт управление event loop достаточно часто, и UI thread блокируется.
2. Частые вызовы `js.pioneer_print(...)` или других JS bridge-функций создают слишком много синхронной нагрузки на главный поток.
3. Рантайм заменяет `time.sleep(...)` на `await asyncio.sleep(...)`, но скрипт без `sleep` или с редкими yield всё равно остаётся почти полностью CPU-bound.
4. Один из bridge-вызовов (`get_dist_sensor_data` или `led_control`) запускает слишком частые обновления состояния/рендера и перегружает сцену.
5. Зависание усиливается из-за отсутствия защитного механизма в Python runtime, который принудительно вставляет yield в долгие циклы.

## Plan

- Добавить только диагностическую инструментализацию.
- Собрать логи о частоте цикла, вызовах bridge и времени между yield.
- После подтверждения причины внести минимальный фикс.
