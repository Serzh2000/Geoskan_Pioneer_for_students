## Единый контракт (обязателен для всех)

- Заголовок панели: 52 px, название 15/650, справа слот состояния (`.pk-chip`), закрытие 36 px (`.panel-close-btn`). Без подзаголовков, eyebrow, hero, h1 внутри панели.
- Тело: `padding: 16px`, секции `.pk-section` с `gap: 20px` и одной линией между ними. Никаких карточек в карточках: карточка (`.pk-device`) только для физических поверхностей — LED-плата, сцена, код.
- Строки списков — `.pk-row` 44 px; выбор — заливка `--accent-soft`; действия строки — `.pk-row__action`, появляются при наведении, место под них зарезервировано (строка не прыгает).
- Поля — `.pk-field`: подпись сверху 12/600, значение справа серым, контрол 36 px из `core/forms.css`; подсказка только там, где без неё непонятно.
- Переключатель режимов — `.pk-seg`, не вкладки с подчёркиванием. Чекбокс «вкл/выкл» — `.pk-toggle` + `.pk-switch`.
- Кнопки — `.btn-primary` / `.btn-secondary` (+ `.btn--sm`, `.btn--full`, `.btn--danger`). Текст — глагол: «Добавить», «Разрешить внешние команды». Одна primary на экран.
- Состояние всегда заливкой. Запрещены: подчёркивания, полоски по краю (`box-shadow: inset 3px 0`), градиенты, свечения, `!important`, захардкоженные цвета вне токенов `base.css` / `panel-chrome.css`.
- Кегли 12/13/15/17, скругления 8 (контролы) / 12 (панели, device) / 16 (диалог). Шрифт `--font-sans`, моно только для индексов, портов, кода.
- Все `id` элементов, к которым привязан TypeScript, сохраняются. Русские подписи, API-имена в оригинале. `aria-*` не ухудшать.
- Обе темы проверяются через токены; никаких отдельных `dark.css` / `light.css`.
- Не трогать `DESIGN.md`, `UX-CONTRACT.md`, `public/style.css` (кроме агента E), чужие файлы из списка владения. Не делать `git commit`, `git stash`, `git checkout` — рабочее дерево общее и содержит чужие незакоммиченные правки.
- Проверка: `npm run type-check` и `npm test` (jest) зелёные; визуально — открыть `http://localhost:3011` нельзя одновременно нескольким агентам, поэтому агент проверяет через type-check/tests, а скриншоты снимает координатор.
