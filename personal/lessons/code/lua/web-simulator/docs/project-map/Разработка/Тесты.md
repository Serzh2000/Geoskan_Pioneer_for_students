# Тесты (`tests/`)

50 файлов `*.test.ts`, запуск через Jest (`node --experimental-vm-modules
node_modules/jest/bin/jest.js`, `npm test`). Конфиг: [jest.config.js](../../../jest.config.js).

Крупные группы по именам файлов:

- **Lua**: `lua-runner`, `lua-runtime`, `lua-autopilot`, `lua-sleep`,
  `lua-periodic-timer`, `lua-mission-guard`, `lua-validation`, `lua-utils`,
  `lua-api-constants`, `lua-flight-integration`, `lua-timed-square-flight` —
  покрывают [[Lua]].
- **Python**: `python-runtime`, `python-runtime-concurrency`,
  `python-camera-frames`, `pioneer-js-bridge`, `external-python-bridge`,
  `external-bridge-frozen-clock` — покрывают [[Python]] и [[External Python Bridge]].
- **Blockly**: `blockly-codegen`, `blockly-debug`, `blockly-python-blocks`,
  `blockly-workspace-controller`, `pioneer-blockly-*` (camera, codegen,
  contract, events, lua-fsm, script-validation, target-support) — покрывают
  [[Editor]] (Blockly-режим).
- **Mission Guide**: `mission-guide`, `mission-guide-validation` — [[Mission Guide]].
- **Окружение/сцена**: `environment-geometry`, `journal-and-training-props`,
  `scene-manager-catalog`, `cargo-contact`, `frames` — [[Environment]],
  [[Scene]], [[Scene Manager]].
- **Сервер**: `mavlink-bridge`, `server-rate-limits` — [[Сервер обзор]].
- **Прочее**: `fsm` ([[Autopilot]]), `state` ([[Core]]), `rc-settings`
  ([[Settings]]), `monaco-completion` ([[Editor]]), `editor-blockly-ui`,
  `logger`, `paths`, `tracing`, `runtime-cleanup`,
  `pioneer-blender-model`, `pioneer-official-examples`,
  `script-execution-notice-failures`/`-scenarios` ([[App]]).

`tests/fixtures/`, `tests/helpers/`, `tests/asset-stub.ts` — общая
инфраструктура тестов.
