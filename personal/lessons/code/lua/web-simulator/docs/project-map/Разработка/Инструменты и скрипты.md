# Инструменты и скрипты (`tools/`, `scripts/`, `package.json`)

## Команды (`package.json`)

| Команда | Что делает |
| --- | --- |
| `npm start` | сервер (порт 3000) + Vite dev-server (порт 3001) параллельно |
| `npm run build` | `vite build` + компиляция `server.ts` в `dist/` |
| `npm run prod` | build + запуск `dist/server.js` |
| `npm run type-check` | `tsc --noEmit` |
| `npm run lint` | eslint (см. [[Известные ограничения и риски]] — часть правил отключена) |
| `npm test` | Jest, см. [[Тесты]] |
| `npm run docs:functions` | генерирует `docs/functions-reference/` |

CI: `.github/workflows/web-simulator-ci.yml` в корне монорепозитория — гоняет
type-check/lint/test на push/PR при изменении файлов этого проекта.

## `tools/`

- `audit_and_refactor.ts`, `revert_lua.ts`, `run_tests.ts` — служебные
  скрипты рефакторинга/тестирования.
- `generate_functions_reference_index.mjs`,
  `generate_marker_dictionaries.mjs` — генерация справочника API
  ([[Документация проекта]]).
- `export_pioneer_blend.py`, `build_training_props_v2.py` — экспорт
  3D-моделей/препятствий из Blender (см. `Модельки/` в корне репозитория),
  связано с [[Environment]] и [[Drone]] (`drone-model/`).
- `debug_bridge_capture_server.py`, `debug_external_bridge_test.py`,
  `install_idle_bridge.py`, `uninstall_idle_bridge.py` — отладка
  [[External Python Bridge]].
- `pioneer_lua_research.py`, `plazlink_analyzer.py`, `pioneer-lua-probes/` —
  исследование реальной Lua-прошивки Pioneer (см.
  `docs/pioneer-lua-firmware-investigation.md`,
  `docs/pioneer-lua-research-evidence.json` в корне репо).
- `playwright/` — вероятно e2e-тесты через Playwright.
- `scratch/` — черновики.

## `scripts/`

- `blockly-api-sanity.cjs` — проверка соответствия Blockly-блоков API (связано
  с [[Editor]]).
