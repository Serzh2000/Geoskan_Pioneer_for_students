# Карта проекта — Web Simulator

> Браузерный симулятор дрона Pioneer для учебных занятий: 3D-сцена (Three.js),
> редактор кода (Monaco + Blockly) на Lua или Python, физика полёта и мост к
> реальным протоколам (MAVLink, `pioneer_sdk`) через локальный Node-сервер.

Это входная точка в vault — граф заметок о том, как устроен проект. Открывай
эту папку (`docs/project-map/`) как отдельный vault в Obsidian, или как
подпапку внутри существующего vault. Для визуального обзора связей см.
[[Карта проекта.canvas]].

## Как читать этот vault

- Заметки в `Модули/` — по одной на каждую папку `public/modules/*`.
- `UI/` — детализация самого большого раздела (`public/modules/ui/`, 178 файлов).
- `Сервер/` — Node/Express бэкенд (`server/`, `python_bridge/`).
- `Архитектура/` — сквозные темы: клиент/сервер разрез, состояние.
- `Разработка/` — тесты, инструменты, документация, известные ограничения.

## Точки входа в код

- [public/main.ts](../../public/main.ts) — точка входа клиента: собирает сцену,
  редактор, UI и раннер скрипта.
- [server.ts](../../server.ts) — точка входа сервера (Express).
- [README.md](../../README.md) — исходная карта проекта одним файлом
  (этот vault — её разворачивание в граф заметок).

## Клиент — модули верхнего уровня

- [[Core]] — глобальное состояние (`simState`, `drones`, `simSettings`)
- [[Drone]] — обвязка над 3D-объектом дрона
- [[Physics]] — модель полёта, интеграция по `dt`
- [[Autopilot]] — FSM полёта, события MCE, параметры автопилота
- [[Lua]] — раннер Lua-скриптов (Fengari), API `ap`/`Sensors`/`Timer`/`camera`
- [[Python]] — два режима исполнения Python (браузерный JS-bridge и серверный)
- [[Editor]] — Monaco + Blockly, автодополнение
- [[Scene]] и [[Environment]] — 3D-сцена, объекты, окружение
- [[UI обзор]] — все панели интерфейса (самый большой раздел)
- [[App]] — верхнеуровневая склейка (уведомления, тема, цикл анимации)
- [[Shared]] — общие утилиты
