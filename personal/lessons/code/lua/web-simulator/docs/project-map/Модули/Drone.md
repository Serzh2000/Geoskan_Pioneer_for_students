# Drone (`public/modules/drone/`)

4 файла. Обвязка над 3D-объектом дрона: обновление позиции/ориентации, сброс,
операции над сценой (добавить/удалить/выбрать дрон).

Тесно связан с `drone-model/` (9 файлов) — вероятно геометрия/загрузка модели
дрона (STL/Blender-экспорт, см. `Модельки/` в корне репозитория).

## Поток данных

[[Physics]] считает новое положение → пишет в [[Core]] (`simState`) →
`drone/` синхронизирует 3D-объект в [[Scene]].

## Связанное

[[Physics]] · [[Core]] · [[Scene]] · [[UI обзор]] (drone-manager — переключение
между несколькими дронами)
