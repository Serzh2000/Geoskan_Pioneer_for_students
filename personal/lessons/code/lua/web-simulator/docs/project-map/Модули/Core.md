# Core (`public/modules/core/`)

5 файлов. Общее состояние симуляции.

- [core/state.ts](../../../public/modules/core/state.ts) — `simState`, глобальный
  `Proxy`-объект, отражающий текущего выбранного дрона из реестра `drones`.
  Единственный источник истины для физики/UI на клиенте — мутация полей
  `simState.*` и есть основной способ поменять что-либо в симуляции. Подробнее
  см. [[Состояние (simState)]].
- `drones` — реестр всех дронов в сцене.
- `simSettings` — глобальные настройки симуляции.

## Кто зависит

Практически все модули клиента читают/пишут `simState`: [[Physics]],
[[Autopilot]], [[Drone]], [[UI обзор]], [[Lua]], [[Python]].
