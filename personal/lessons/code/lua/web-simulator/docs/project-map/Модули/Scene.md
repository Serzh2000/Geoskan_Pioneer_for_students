# Scene (`public/modules/scene/`)

19 файлов (в `core/`, `interaction/`, `objects/`). 3D-сцена на Three.js: камера,
рендер-цикл, выбор объектов мышью, размещение объектов дрона/окружения.

- `scene/core/` — инициализация сцены, камеры, рендерера.
- `scene/interaction/` — клики/драг по 3D-объектам (например, в
  [[Scene Manager]] UI-панели для расстановки препятствий).
- `scene/objects/` — объекты сцены.
