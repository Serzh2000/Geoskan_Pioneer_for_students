# Physics (`public/modules/physics/`)

14 файлов. Модель полёта дрона: ручной режим (управление с клавиатуры/геймпада)
и авто-режим (команды от [[Autopilot]] FSM). Интегрирует скорость/позицию по
`dt` на каждом кадре анимации ([[App]]/`animation-loop.ts`).

Использует [[Shared]] (`gate-geometry.ts`, `math.ts`) для геометрических
вычислений (например, ворота/препятствия трассы).

## Поток данных

[[Lua]] / [[Python]] → команды автопилоту → [[Autopilot]] (FSM) → `physics/`
→ обновляет [[Core]] (`simState`) → [[Drone]] синхронизирует 3D-объект.
