# MAVLink Bridge (`server/mavlink-bridge.ts`)

Мост к реальному дрону по протоколу **MAVLink** через UDP — позволяет
симулятору (или его UI) общаться с настоящим полётным контроллером, а не
только с симуляцией. Использует общие типы подключения из
`server/pioneer-connection.ts`. Тест: `tests/mavlink-bridge.test.ts`.
