# Состояние: `simState`

`simState` в [public/modules/core/state.ts](../../../public/modules/core/state.ts)
— глобальный `Proxy`-объект, отражающий текущего выбранного дрона из
реестра `drones`. **Единственный источник истины** для физики/UI на клиенте:
мутация полей `simState.*` — это и есть основной способ поменять что-либо в
симуляции (позицию дрона, режим полёта, показания сенсоров и т.д.).

## Компромисс: глобалы через `window as any`

Помимо `simState`, в нескольких модулях используется `window as any` для
протаскивания глобалов (`THREE`, `fengari`). Это осознанный компромисс ради
совместимости с раннерами [[Lua]]/[[Python]], но **не образец для нового
кода** — см. [[Известные ограничения и риски]].

## Кто читает/пишет

- [[Physics]] — пишет новую позицию/скорость каждый кадр.
- [[Autopilot]] — пишет целевые режимы/состояние FSM.
- [[Drone]] — синхронизирует 3D-объект с `simState`.
- [[UI обзор]] — почти все панели читают текущего дрона отсюда.
- [[Lua]] / [[Python]] — скрипт ученика читает сенсоры и пишет команды через
  API-обвязку (`ap.*`, `Sensors.*`), которая под капотом дергает `simState`.
