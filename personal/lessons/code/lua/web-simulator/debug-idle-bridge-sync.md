# Debug Session: idle-bridge-sync

Status: OPEN

## Symptom

- Пользователь запускает обычный Python-код через `Python IDLE`.
- Ожидается, что bridge отправит команды в локальный сервер, а браузер начнет анимацию.
- Фактически "ничего не происходит".

## Expected

- Вызовы `pioneer_sdk.Pioneer.*` из `IDLE` должны попадать в локальный HTTP bridge.
- Сервер должен фиксировать входящие события.
- Браузер должен забирать события и применять их к симулятору.

## Hypotheses

1. Python hook в `IDLE` вообще не активируется, и `pioneer_sdk` не патчится.
2. Hook активируется, но POST на `http://127.0.0.1:3000/api/external-python-bridge/event` не уходит или падает.
3. Сервер получает события, но очередь `/api/external-python-bridge/events` пуста или не отдает их клиенту.
4. Браузерный polling не стартует или не применяет события к существующим `pioneer_*` bridge-функциям.
5. События применяются, но создается/выбирается не тот drone id, поэтому пользователь визуально не видит анимацию.

## Planned Evidence

- Проверить, подхватывается ли bootstrap в системном Python.
- Проверить, отправляет ли Python runtime POST события на локальный сервер.
- Проверить, видит ли сервер события в очереди.
- Проверить, стартует ли браузерный polling и создает ли внешний дрон.

## Notes

- До получения runtime evidence бизнес-логика не меняется.
