# Примеры

Единственный источник примеров: из них вставляется код в [учебник](../book), их же показывает [веб-симулятор](../simulator) в выпадающем списке «Примеры».

| Каталог | Что внутри |
|---|---|
| `lua/` | примеры глав по Lua: `02_sensors`, `03_rc_control`, `04_language`, `05_leds`, `06_missions` |
| `lua-tasks/` | решения практических заданий (`05_leds`, `07_advanced_missions`) |
| `python/` | скрипты на `pioneer_sdk`: основы, управление полётом, камера, ArUco, рой, навигация |
| `python-answers/` | ответы к упражнениям по Python |

## Как это работает

* Книга ссылается на файлы окружением `egin{codefile}{lua/04_language/...}`: путь считается от этого каталога.
* Каждый файл, на который ссылается книга, прогоняется тестом `simulator/tests/lessons-book-examples.test.ts`: Lua в настоящем рантайме симулятора, Python по выводу или на поддельном SDK.
* Симулятор держит у себя копии (`simulator/examples`, `simulator/examples-python`), чтобы деплой одной папки `simulator/` работал без остального репозитория. Копии создаёт `npm run sync-examples`; **правьте примеры здесь, не в копиях**.
