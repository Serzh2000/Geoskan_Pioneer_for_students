# Стендовые пробы Pioneer Lua

Эти файлы **подготовлены, но не запускались на реальном контроллере**. Проверена только компиляция штатным `C:\PioneerStation\tools\luac.exe` (Lua 5.3.3). В пробах используются светодиоды, часы, таймеры и чтение имён API. Команд автопилоту и записи параметров нет.

Каждый файл загружается и запускается отдельно. Загрузка заменяет установленный скрипт, поэтому сначала нужно получить его резервную копию и записать модель платы, версию прошивки, параметры запуска и состояние компонента Lua. Версия прошивки из имени локального файла не заменяет чтение версии аппарата. Проверки проводятся на неподвижном стенде с исключённым запуском пропеллеров.

| Файл | Наблюдение | Как читать результат |
|---|---|---|
| `01-api-surface.lua` | Наличие четырёх API, список констант и время | LED0..3: зелёный — функция доступна, красный — отсутствует. Точный список констант и чисел требует рабочего канала вывода `print`; его наличие ещё не проверено. |
| `02-timer-lifecycle.lua` | Автостарт и отложенное действие `stop` | До 1 с таймер не запускается явно; LED2 красный означает ранний callback. После остановки в 1.6 с LED1 красный означает callback из очереди. LED3 зелёный после 2.5 с — конец окна наблюдения. |
| `03-sleep-dispatch.lua` | Могут ли другие таймеры исполняться во время `sleep` в callback | LED0 красный во время `sleep`; затем зелёный — другие тики произошли, синий — не произошли. Это наблюдение порядка, не измерение точной частоты. |
| `04-pending-timer-capacity.lua` | Сколько из 20 однократных таймеров принимаются | После 2 с зелёные LED0..3 показывают младшие биты счётчика, синий LED3 — бит 4. Только синий LED3 = 16; синий LED3 + зелёный LED2 = 20. Красный LED0 означает исключение при регистрации. |
| `05-no-callback.lua` | Жизненный цикл скрипта без глобального callback | LED0 красный — исполнился основной код; зелёный — сработал таймер. Затем повторить с добавленным пустым `function callback(event) end`. Это **не** проверяет принятие полётных команд без callback. |

`print` используется только при наличии функции; световая индикация в пробах 02–05 работает независимо от него. Отсутствие сообщений не доказывает, что callback не исполнился. Для пробы 01 константы можно позднее кодировать светодиодами по одной, если станция не показывает вывод.

Заполнять протокол отдельно для платы и симулятора:

```text
Дата / плата / версия прошивки:
SHA-256 скрипта:
Способ старта / время после включения:
Lua run / status / memoryUsage до и после (если доступны):
Светодиоды / сообщения / наблюдённый порядок:
Повтор 1 / повтор 2 / повтор 3:
Вывод и оставшиеся неоднозначности:
```

Для `time()` повторить запуск 01 через известный интервал без отключения питания: это позволит отличить время включения от времени запуска скрипта. Для числовых значений событий и смысла `status` сначала нужен проверенный способ вывода; произвольные числовые команды автопилоту для этого не требуются.
