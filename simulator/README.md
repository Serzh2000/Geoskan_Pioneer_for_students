# Web Simulator Pioneer

Веб-симулятор для обучения программированию и отладки автономных миссий на квадрокоптерах «Геоскан Пионер». Здесь можно безопасно писать и запускать программы на Lua, Python или Blockly, наблюдать полёт в 3D-сцене и проверять логику миссии без реального дрона.

**Автор:** Корягин Сергей Андреевич, аспирант СПбГЭТУ «ЛЭТИ» и педагог дополнительного образования.

**Сайт автора:** [sakoryagin.ru](https://sakoryagin.ru)

**Запуск симулятора:** [simulator.sakoryagin.ru](https://simulator.sakoryagin.ru)

## Главное

- 3D-сцена с ареной, препятствиями, маршрутами и несколькими дронами.
- Blockly, Lua и Python с автодополнением и запуском кода в браузере.
- Автопилот: арминг, взлёт, посадка, полёт по локальным точкам, yaw и ручное управление.
- Датчики, камера, LED-лента, телеметрия и поддержка геймпада.
- Учебные задания с проверкой результата.
- Внешнее управление из `pioneer_sdk` и интеграция по MAVLink.

## Быстрый старт разработчика

Нужен Node.js 20 или новее.

На Windows после установки зависимостей (`npm install`) откройте **start.cmd**
двойным кликом или выполните в PowerShell:

```powershell
.\start.cmd
```

Этот запуск поднимает весь симулятор: интерфейс и сервер API. Окно запуска
оставьте открытым; для остановки нажмите Ctrl+C. Запуск исправляет некорректные
кавычки в PATH только для своего процесса, не меняя настройки Windows.

На других системах:

```bash
npm install
npm start
```

Откройте **http://127.0.0.1:3011/** — здесь интерфейс и актуальный учебник из исходников.
Сервер API использует порт `3010` и перенаправляет браузер на `3011`, не отдавая старую
сборку из `dist/public`. Порты `3000` и `3001` не используются: они могут быть заняты
другими проектами. Если порт занят, запуск завершится с ошибкой вместо смены адреса.

<summary>Процедурная учебная местность</summary>

Откройте **Руководство → О курсе и полигонах**, выберите местность и seed,
нажмите **Добавить полигон в сцену**. В менеджере сцены также доступны готовые шаблоны.
**Земля** показывает всю карту; кнопка наведения возле объекта открывает его в орбите.

Открытый полигон и лаборатория ArUco — 100 × 100 м. Лес, холмы, микрорайоны,
промышленный район и экспедиция — 180 × 180 м. В них есть река и озеро, мосты,
связанные улицы, станция с платформой и поездом, частные дома, дворы, поля и рощи.
Состав районов зависит от профиля, а расположение и детали воспроизводятся по seed:
seed выбирает сторону реки и станции, форму озера, изгиб дороги и то, какой квартал чем
станет (рядом с озером всегда остаются поля или парк). Одиннадцать моделей второй партии —
сарай, силос, ветрогенератор, радиомачта, контейнеры, солнечные панели, теплица, фонарь,
остановка, тюки сена и камни — распределяются по профилям: ветряки и мачты на холмах,
контейнеры и панели у промзоны, остановки вдоль дороги, камни повсюду.
Третья партия (шесть моделей): церковь у деревни, АЗС у дороги, портальный кран у промзоны, а также
ЛЭП вдоль края карты (опоры с натянутыми проводами) и малый аэродром — полоса, ангар и ветроуказатель — в холмах и лесу.
Старт и центральный учебный коридор остаются свободными.

Архитектура и проверки: [план местности](docs/procedural-world-plan.md).
Исходники первых четырёх моделей и экспорт — `public/assets/models/props/landscape-kit-v1.*`, второй партии
(одиннадцать моделей) — `landscape-kit-v2.*`, третьей (шесть моделей) — `landscape-kit-v3.*`. Геометрию проверяют
`node tools/validate-landscape-assets.mjs`, `...-v2.mjs` и `...-v3.mjs`. Вторую партию пересобирает
`blender --background --factory-startup --python tools/build_landscape_assets_v2.py`
(сначала удалите старый экспорт или задайте `REBUILD_LANDSCAPE_KIT = True` в сессии Blender MCP).

Живой мир: после «Запуска» вращаются роторы ветряков, по дорогам ездят машины (по правой полосе, в обе стороны), над аэродромом
летает самолёт. На карте происходит четыре события, которые дрон может заметить сверху: горит дом, рвётся провод ЛЭП, в квартире
орудует вор, на улице дерутся. Службы — абоненты `mailbox` со своими бортомерами: пожарная часть 101, полиция 102, ремонтная бригада 103.

```lua
mailbox.send(101, "fire 40 -12")     -- пожарные выедут к точке (x y сцены), раскатают рукав и потушат
mailbox.send(103, "repair 55 44")    -- бригада поднимет лестницу к обрыву и починит ЛЭП
mailbox.send(102, "police 80 30")    -- полиция задержит вора или драчуна и увезёт в отделение
local hull, text = mailbox.receive(true)   -- "accepted 12" -> "arrived" -> "done" | "nothing found" -> "home"
```

Неверные координаты не прощаются: бригада приезжает, ничего не находит (допуск 22 м) и уезжает ни с чем. Пожарные сами зовут полицию,
но она только оцепляет улицу и никого не задерживает. Сцены покрыты тестами `tests/world-scenarios.test.ts`.

Время суток, сезон и погода (дождь, снег, облака) меняются кнопкой «Окружение» под сценой; без неё освещение остаётся как в лаборатории.
Все карты занимают всё поле 600 × 600 м; профиль «Большой город» строит кольцевую дорогу, проспект, сетку улиц, эстакаду через железную
дорогу, школу, больницу, торговый центр, рестораны с террасами, парки, грузовой двор, пожарную часть и отделение полиции.
Модели новых зданий — `landscape-kit-v5.*` (`tools/validate-landscape-assets-v5.mjs`).

<summary>Примеры программ</summary>

Lua: взлёт, полёт в точку и посадка по подтверждённым событиям автопилота.

```lua
function callback(event)
  if event == Ev.ENGINES_STARTED then
    ap.push(Ev.MCE_TAKEOFF)
  elseif event == Ev.TAKEOFF_COMPLETE then
    ap.goToLocalPoint(1, 0, 1)
  elseif event == Ev.POINT_REACHED then
    ap.push(Ev.MCE_LANDING)
  end
end

ap.push(Ev.MCE_PREFLIGHT)
```

Python: полёт по квадрату с `pioneer_sdk`.

```python
from pioneer_sdk import Pioneer
import time

drone = Pioneer()
drone.arm()
time.sleep(1)
drone.takeoff()

for x, y in ((1, 0), (1, 1), (0, 1), (0, 0)):
    drone.go_to_local_point(x=x, y=y, z=1, yaw=0)
    while not drone.point_reached():
        time.sleep(0.1)

drone.land()
drone.disarm()
```

Больше примеров: [Lua](examples) и [Python](examples-python).

<details>
<summary>Внешний Python, камера и MAVLink</summary>

Чтобы запускать обычный `pioneer_sdk` из IDLE, PyCharm или терминала, один раз установите мост:

```bash
python tools/install_idle_bridge.py
```

После этого укажите в `ip` URL симулятора. Команды и камера пойдут через HTTPS, поэтому это работает и за NAT:

```python
from pioneer_sdk import Pioneer, Camera

url = "https://simulator.sakoryagin.ru"
drone = Pioneer(ip=url, mavlink_port=8001)
camera = Camera(ip=url, port=18001)
```

Перед запуском выберите дрон в панели **Рой** и нажмите «Разрешить внешние команды». Когда URL симулятора не указан, установленный мост не меняет работу с настоящим Pioneer.

Для MAVLink UDP по умолчанию используется порт `8001`; для камеры — `18001`. Этот путь удобен в локальной сети. Для внешнего Python и камеры через интернет используйте HTTPS-мост.
</details>
