# Совместимость с официальными Lua-примерами

Проверено 16 сентября 2026 года.

## Источники

- 12 файлов из `C:\PioneerStation\examples`.
- 14 файлов из [geoscan-llc/pioneer-lua-example](https://gitflic.ru/project/geoscan-llc/pioneer-lua-example), коммит `6e7b6d4a8229390d03d890eb98e95624538ec8f6`.
- Неизменённые копии лежат в `tests/fixtures/pioneer-official/{station,gitflic}`. Имена, источники и SHA-256 записаны в `manifest.json`. Исходные каталоги не изменялись. Копии предназначены для регрессионных проверок; авторство принадлежит авторам исходных примеров.

## Проверка

`tests/pioneer-official-examples.test.ts` исполняет каждый из 26 файлов в настоящей Fengari VM с Lua-мостом, планировщиком таймеров, обработкой событий, FSM и физикой симулятора: 120 секунд модельного времени с шагом 1/60 секунды, пустая сцена, стандартное начальное состояние.

Проверяются отсутствие аварий Lua/FSM, отсутствие ложных предупреждений и блокировок перед запуском. Для полётных примеров дополнительно проверяются переход к полёту по точкам и завершение в IDLE. Для RC-примера канал 8 кратковременно включается и затем возвращается в выключенное положение, согласно инструкции в примере.

Все 26 файлов проходят эти проверки. Это ограниченный воспроизводимый сценарий, а не гарантия при любых внешних условиях: препятствия, разряженная батарея, изменённые параметры и действия оператора влияют на полёт.

Проверка выполняется без WebGL и физического оборудования. Для камеры проверяется выполнение Lua и `sleep`; браузерный захват изображения, содержимое фото/видео, MediaRecorder и загрузка файлов этим тестом не проверяются. Датчики получают модельные значения. LED и GPIO изменяют состояние симулятора, а не физическую периферию.

## Исправления

1. Проверка кода больше не принимает объявления функций/методов за немедленное выполнение команд. Одинаковые задержки таймеров внутри функций не считаются доказательством одновременного запуска: функции могут вызываться в разное время или из взаимоисключающих веток. Проверка одинаковых задержек стартовых таймеров сохранена.
2. Добавлена глобальная `fromHSV`, используемая официальной LED-матрицей. Для неё и `Ledbar.fromHSV` применяются градусы оттенка и проценты насыщенности/яркости с результатом RGB 0..1.
3. Положительные задержки, включая `0.003` в LED-примере, больше не увеличиваются до 0.05 секунды. Реальная частота вызовов ограничена шагом симуляции.
4. Неактивный RC-переключатель ARM больше не отменяет каждую команду подготовки от работающего скрипта. Явное переключение ARM из включённого состояния в выключенное сохраняет отключение двигателей и проверяется отдельным тестом.
5. `examples/timed-square-flight.lua`: таймеры 20–90 секунд регистрируются один раз при старте программы. Событие завершения взлёта задаёт только первую точку. Значение `Timer.callLater` остаётся относительной задержкой, как в API Пионера; при регистрации на старте она отсчитывается от запуска.

Официальное описание таймеров: [Lua API](https://docs.geoscan.ru/pioneer/programming/lua/lua.html). Пример HSV: [проекты с LED-модулем](https://docs.geoscan.ru/pioneer/learning-cases/team_projects/ledCases/ledCases-main.html).
