# Аудит объяснений в уроках Академии

Претензия: «не объясняется, как работает светодиод, что такое R G B, как задаются параметры».

## Что было

Карточка миссии показывает ученику поле `summary` — оно бралось из `academy/catalog.ts` (`explanation`). Это была одна-две абстрактные фразы вида «Индекс выбирает элемент. Первый элемент API имеет индекс 0» или «Максимум зависит от API». Формат команд, единицы и диапазоны жили только в тексте задания и подсказке, а подсказка скрыта за кнопкой. Из 108 уроков (72 Lua + 36 Python-vision) дыры были почти во всех: ни одного не было с полным ответом на «что это / как работает / как задаются параметры / что увидим / почему».

Главные дыры (урок → чего не хватало):

| Уроки | Дыра |
|---|---|
| 10–14, 17–19 (светодиод) | не сказано, что такое светодиод, каналы R/G/B, смешение цветов, диапазон 0–1 (Lua) против 0–255 (Python), порядок аргументов, индекс с нуля, что 255 — «все светодиоды», яркость = общая сила каналов |
| 3–4, 18, 32–37 (arm, состояния, события) | arm, «состояние автопилота», событие, callback (обработчик) не определены; для Python — что `ARMED` — это то, что в Lua называется PREFLIGHT |
| 28–31, 35 (время) | чем отличается `Timer.callLater` (отсчёт от создания) от `time.sleep` (паузы складываются); что такое период мигания |
| 37–53 (полёт) | оси X/Y/Z и направление, метры, начало координат, что команда движения не равна прибытию, что подтверждает прибытие, допуск, радианы для курса |
| 56–63 (полигоны) | габарит винтов, seed, зачем запас и промежуточные точки |
| 64–72 (телеметрия) | что такое телеметрия, период опроса, None/nil, ошибка со знаком, лимит скорости |
| 73–81 (камера) | пиксель, порядок `shape` (высота, ширина), ось Y кадра вниз, BGR, поле зрения, None-кадр |
| 82–108 (ArUco) | ID — номер, а не расстояние; словарь `DICT_6X6_250`; формат результата `detectMarkers`; знак ошибки; скорость в м/с, длительность 0,5 с команды `set_manual_speed`; мёртвая зона |
| 3 (Python) | задание говорило «состояние PREFLIGHT», а Python возвращает строку `ARMED` — исправлено через теги `<lua>/<py>` |

В блочных уроках (`lessons/pioneer/*`) у каждого урока уже есть поля `theory` и `notes`, а RGB разобран в отдельном уроке «Свой цвет из RGB»; в первом уроке «Цвет светодиодов» добавлена фраза про смешение трёх каналов.

## Что сделано

* Новый файл `academy/explainers.ts`: «Как это устроено» для всех 108 уроков (2–7 предложений, термины вводятся при первом употреблении, жирным выделены новые слова). Куски, разные для языков, обёрнуты в `<lua>…</lua>`/`<py>…</py>`; формат LED-команды (`LED_FORMAT`) вынесен в общую константу, чтобы он не расходился в уроках 10–18.
* Объяснение подключено везде, где раньше был `explanation`: поле `summary` (карточка миссии), `lessonIntro` и `teaching.device` (`practices/shared.ts`, `drone.ts`, `vision-shared.ts`); теперь оно локализуется под язык.
* `catalog.ts` не тронут — его краткое `explanation` остаётся для оглавления.
* Справочник: подробные описания `Ledbar.new`, `Ledbar:set` (Lua) и `Pioneer.led_control` (Python): каналы, диапазоны, нумерация с 0, `255` = все.
* Исправлено расхождение задания урока 3 с Python.
* Оценщики (`academy/evaluation/*`) не менялись.

## Тесты

`tests/academy-explainers.test.ts`: у каждого урока есть объяснение нужной длины и числа предложений; теги не протекают; Lua-текст не содержит Python-API и наоборот; LED-уроки объясняют каналы, индекс и диапазон своего языка (Lua — от 0 до 1, без 255; Python — от 0 до 255); в уроках про координаты, курс, скорость, `shape` названы единицы и порядок; `summary` скомпилированных уроков совпадает с объяснением.

## Что осталось

* Объяснение показывается на вступительной карточке миссии; на карточках шагов остаётся только само задание и скрытая подсказка. Если захочется «шпаргалку» на каждом шаге, нужна правка `learning/controller.ts` (вне этой задачи).
* Мини-схемы и таблицы в карточке не поддерживаются (`rich()` понимает только `код` и **жирный**); цвета-смешение описаны словами.
* Тексты заданий (`task`) и подсказки в `practices/*.ts` стоит дальше вычитывать выборочно у учителя; дыры в них — единичные (уже был точечный аудит).
* Углы курса: направление положительного поворота в тексте не указано (в симуляторе не проверялось).
