# UI (`public/modules/ui/`)

**178 файлов — самый большой раздел проекта.** Все панели интерфейса.

- `index.ts`, `workspace-view.ts` — сборка рабочего пространства (компоновка
  панелей, вкладок).
- `mobile-editor-viewport.ts` — адаптация под мобильный вьюпорт.
- `scene-onboarding.ts` — онбординг по 3D-сцене для новых пользователей.

## Подразделы (см. отдельные заметки)

- [[Mission Guide]] — методические уроки (самый сложный подраздел)
- [[Panels]] — боковые панели (телеметрия, каналы, LED-матрица, статистика)
- [[Settings]] — настройки: геймпад, калибровка, параметры автопилота, рендер
- [[Scene Manager]] — панель управления объектами 3D-сцены
- [[Drone Manager]] (`managers/drone-manager*`) — переключение/добавление дронов
- `api-docs/` — встроенная справка по API (см. [[Документация проекта]])
- `context-menu/`, `controls/`, `info/` — контекстное меню, элементы
  управления, инфо-блоки

Разметка панелей — HTML-фрагменты в `public/fragments/panels/*.html`,
подгружаемые этим модулем (`sidebar-panels.html`, `sidebar-tabs.html`,
`global-header.html`, `main-scene.html`).
