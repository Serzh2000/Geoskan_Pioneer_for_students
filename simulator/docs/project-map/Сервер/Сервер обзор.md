# Сервер (`server/`, точка входа `server.ts`)

Express-сервер: раздаёт статику клиента (в проде — `dist/public`) и держит
несколько API-роутов.

- [server.ts](../../../server.ts) — точка входа, прод.
- [server-dev.ts](../../../server-dev.ts) — точка входа для разработки (запускается
  через `npm run server`, параллельно с `npm run vite`).
- [[Python Runtime]] (`server/python-runtime.ts`) — выполняет присланный
  клиентом Python-код локальным процессом.
- [[External Python Bridge]] (`server/external-python-bridge.ts`) —
  событийный мост для внешнего Python, запущенного пользователем отдельно.
- [[MAVLink Bridge]] (`server/mavlink-bridge.ts`) — мост к реальному
  MAVLink/дрону по UDP.
- `server/pioneer-connection.ts` — общие типы конфигурации подключения.

## Важно

Сервер выполняет **произвольный код по запросу** (`/api/python-runtime/run`).
Подробности рисков и переменных окружения для защиты (CORS, rate limit,
лимиты процесса) — см. [[Известные ограничения и риски]].
