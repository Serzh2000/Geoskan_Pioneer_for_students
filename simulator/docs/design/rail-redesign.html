Левая рельса: один язык для всех панелей

Шесть панелей и учебник собраны из одного набора: заголовок 52 px со слотом состояния, плоские секции вместо вложенных карточек, строки 44 px, поля с подписью сверху, сегментный переключатель, чип состояния. Состояние всегда передаётся заливкой, не обводкой и не подчёркиванием. Скругления 8/12/16, контролы 36 px, кегли 12/13/15/17.

Рельса и панели инструментов

Рельса делится на две группы: рабочие панели сверху, служебные снизу, между ними разделитель. Активная вкладка — заливка акцентом, подсказка появляется у каждой кнопки одинаково. Пульт больше не перекрывает сцену: он такая же панель, 440 px, дрон остаётся виден при проверке стиков.

Редактор оставляет свой заголовок-тулбар — это единственный допустимый вариант заголовка. Кнопки тулбара те же 36 px, что и у закрытия.
  • Заголовок — 52 px, название 15/650, слот состояния (чип), закрытие 36 px. Без подзаголовков, без hero.
  • Секция — заголовок 13/650 + счётчик или действие справа; между секциями 20 px и одна линия. Никаких карточек в карточках.
  • Строка — 44 px, иконка 28, имя 13/600, подпись 12 muted; выбор — заливка акцентом; действия появляются в строке, место под них зарезервировано.
  • Поле — подпись сверху 12/600, значение справа серым, контрол 36 px, подсказка 12 только если без неё непонятно.
  • Сегмент — вместо вкладок с подчёркиванием; активный — приподнятая заливка.
  • Чип — тон заливкой: серый, успех, предупреждение, ошибка, акцент. Одна точка, текст, без иконок.
  • Кнопки — primary оранжевая, secondary поверхность с линией, 36 px, 8 px. Текст — глагол: «Добавить», «Разрешить внешние команды».
  • Устройства — единственные «карточки»: LED-плата, сцена, код. Они тёмные в обеих темах, потому что это физика, а не UI.

Учебник пилота

Один файл стилей вместо двадцати шести. Оглавление слева, маршрут из пяти остановок, одна колонка 720 px для чтения, вся ширина для работы. Сцена живёт внутри своей секции и никогда не вылезает под маршрут. Нет дублирующей строки «Шаг 1 из 5 · Идея» — об этом говорит сам маршрут.

Где живёт программа

Редактор хранит команды. Запуск передаёт их интерпретатору, а сцена показывает результат. Изменение текста само по себе не запускает дрон.

Перед началом

Комментарий Lua начинается с --, Python — с #. Комментарий объясняет код человеку и не выполняет действие.

ap.push(Ev.MCE_PREFLIGHT)Переводит автопилот в предполётную проверку. Без неё команда взлёта игнорируется.

Что исправляет редизайн

Выписано из живого симулятора на 13 октября 2026, светлая и тёмная тема, 1100–1400 px.

  • Учебник: 26 CSS-файлов, 4609 строк, 6 слоёв переопределений (modal → page → page-workbench → lesson-polish → course-shell → flight-workbook) плюс отдельные dark/light файлы. 29 % классов не используются, 412 цветов захардкожены, палитра slate (#0f172a, #94a3b8) из другого проекта. Замена: один guide.css на токенах.
  • Учебник: липкий маршрут перекрывает кнопки камеры сцены на шаге Практика; сцена захватывает колесо, страница не прокручивается над ней.
  • Учебник: селекты в практике синие (hardcoded blue), в нарушение DESIGN.md.
  • Учебник: дубли — «Шаг 1 из 5 · Идея» под маршрутом; на шаге Результат три карточки («Что наблюдать», «Результат опыта», «Живая сцена») говорят одно и то же; у Blockly-трека подпись «10 заданий · Lua».
  • Учебник: закрытие по потере фокуса — модал закрылся при клике вне окна/переключении, прогресс шага сбрасывать нельзя.
  • Пульт занимает весь экран, скрывая сцену и дрон; кнопки запуска сцены наплывают на строки каналов. Hero с eyebrow «УПРАВЛЕНИЕ ДРОНОМ», h1 и пилюля; вкладки с подчёркиванием; «ШАГ 01 / ШАГ 02» в боковой колонке.
  • Рой: маркетинговая вводка «управляйте составом без перегруженного интерфейса», eyebrow с иконкой, три вложенные карточки, «Удалить» как вторая главная кнопка внизу, моноширинные блоки с адресами.
  • Настройки: аккордеон из пяти карточек с точкой-акцентом и подзаголовком у каждого контрола («Оптимальная ширина для обзора маршрута»); чекбокс вместо переключателя; окно автопилота спрятано за «alert».
  • Телеметрия: три карточки в карточке, бейджи «0–3» и «5 × 5» как пилюли; описание матрицы занимает две строки.
  • Рельса: переключатель темы оформлен как вкладка и стоит между панелями; подсказки сделаны двумя способами (title и data-tooltip); нет разделения рабочих и служебных кнопок.
  • Ширины панелей разные по умолчанию (320/360/420/100 %), заголовки где-то с подзаголовком, где-то без; у Настроек нет кнопки закрытия.
  • Оставляем: тулбар редактора, менеджер сцены (ближе всех к кит-у), 52 px заголовок, 36 px контролы, токены base.css и panel-chrome.css.
