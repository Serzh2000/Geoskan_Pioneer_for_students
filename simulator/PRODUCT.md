## Users

Подтверждено автором: две аудитории поровну.

- Школьники на занятиях кружка дополнительного образования: педагог рядом, задания идут по учебнику, в классе есть реальный квадрокоптер «Геоскан Пионер».
- Школьники и студенты дома, самостоятельно, на сайте simulator.sakoryagin.ru: без педагога и без дрона.

Работа одного человека: понять одно понятие, изменить небольшую программу, запустить её и увидеть, что сделал аппарат. Один и тот же интерфейс должен выдерживать обе ситуации: в классе — быстрый переход между уроком, кодом и сценой при педагоге, дома — самодостаточные объяснения, прогнозы и автопроверка вместо взрослого рядом.

## Product Purpose

Веб-симулятор для обучения программированию квадрокоптеров «Геоскан Пионер» и отладки автономных миссий без реального дрона. Ученик пишет программу на Lua, Python или Blockly, запускает её в браузере, наблюдает полёт в 3D-сцене, телеметрию и светодиоды и получает проверку результата.

Успех: ученик самостоятельно проходит уроки встроенного курса, а его код без правок переносится на настоящий аппарат.

## Positioning

Подтверждено автором как главное: **работает в браузере без установки**. Открыл сайт — дрон, сцена, редактор и учебник уже работают; ничего ставить не нужно ни дома, ни на школьном компьютере.

Опора на это (из репозитория, не подтверждалось отдельно): интерпретатор Lua, Python-мост и Blockly выполняются в самом браузере; backend нужен только для внешнего управления из Python IDLE по MAVLink.

## Operating Context

- Занятие кружка: педагог, учебник (PDF/LaTeX в `book/tex`), реальные Пионеры, школьные Windows-ПК; локальный запуск через `start.cmd` (интерфейс 3011, API 3010).
- Дом: публичный сайт simulator.sakoryagin.ru, свой компьютер, никого рядом.
- Внутри продукта: редактор кода (Monaco/Blockly), 3D-сцена с ареной, полигонами и несколькими дронами, телеметрия и LED-матрица, пульт (геймпад), менеджер сцены, встроенный пошаговый учебник, справочник API.
- Сопутствующие инструменты: Python IDLE и `pioneer_sdk` для внешнего управления; готовые примеры Geoscan в `examples/` и `examples-python/`.

## Capabilities and Constraints

Из репозитория (факты реализации):

- Языки: Lua (API автопилота как в прошивке: `ap`, `Ev`, `Timer`, `Sensors`, `Leds`), Python (`pioneer_sdk`), Blockly с генерацией кода.
- Автопилот: арминг, взлёт, посадка, полёт по локальным точкам, yaw, ручное управление; датчики, камера с ArUco, LED-лента, телеметрия, геймпад; несколько дронов.
- Курс: 108 последовательных уроков (Python — все 108, Lua — первые 72, Blockly — отдельный трек из 10 практикумов), каждый урок в пять шагов: Идея, Прогноз, Практика, Результат, Разбор, с автопроверкой по фактическому поведению сцены.
- Процедурная учебная местность 600 × 600 м по seed: город, лес, холмы, промзона, аэродром, живой трафик, события и службы (`mailbox`).
- Язык интерфейса — русский; имена API сохраняют написание прошивки.
- Темы: светлая и тёмная, переключаются во время работы.
- Desktop — основной режим; узкие окна (до 980 px) обязаны сохранять все уроки, инструкции и действия.

Не подтверждено, оставлено открытым (автор не выбрал ограничения):

- Обязательность офлайн-работы на слабых школьных ПК как требование к производительности.
- Право использовать бренд и логотипы «Геоскан» (сейчас в интерфейсе их нет; проект авторский).
- Требование синхронизировать термины интерфейса с PDF-учебником.

## Product Principles

1. Сначала наблюдение: каждое действие ученика должно быть видно на сцене, в телеметрии или в журнале, а не только в тексте.
2. Один путь к любому инструменту: учебник, код и сцена всегда на расстоянии одного действия, и в классе, и дома.
3. Код переносим: то, что работает в симуляторе, работает на реальном Пионере; никаких удобных, но несуществующих команд.
4. Самодостаточность для домашнего ученика: объяснение, прогноз, проверка и разбор заменяют педагога, а не требуют его.
5. Ничего не устанавливать: любая новая возможность должна работать из браузера.
