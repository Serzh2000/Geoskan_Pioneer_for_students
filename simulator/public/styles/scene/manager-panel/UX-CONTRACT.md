# Менеджер сцены: контракт дизайна

Панель собрана из общего кита `styles/panels/panel-kit.css` (`pk-seg`, `pk-section`, `pk-row`,
`pk-field`, `pk-kbd`, `btn--sm`). Компоненты имеют единственных владельцев: `controls.css` —
алиасы `--sm-*` (нужны каталогу), поля и раскладка кнопок; `panel.css` — вкладки, дерево,
раскрывающиеся строки и инспектор; `catalog.css` — каталог объектов (модальное окно).
Палитра наследуется из общего chrome панелей (`--pc-*`). Состояние передаётся только заливкой:
без подчёркиваний, полос, градиентов, свечений и `!important`.

| Что | Правило |
| --- | --- |
| Вкладки «Объекты / Свойства» | `.pk-seg` > `.pk-seg__btn` (`role="tab"`), активная — заливка `is-active`. У «Свойства» маленький чип-счётчик выбранных объектов, виден только когда вкладка неактивна и что-то выбрано |
| Секции | `.pk-section` без карточек: заголовок 13/650 + мета + кнопка в одной строке, между секциями одна линия |
| Структура вкладки «Объекты» | «Объекты сцены» + счётчик + primary «Добавить» → поиск → дерево → строка выбора → подсказка с `.pk-kbd` → две строки-ссылки «Готовые полигоны» и «Файл сцены» |
| Строка дерева | `.pk-row` 44 px: шеврон, иконка 28, имя 13/600, подпись 12 muted; выбор — заливка `--accent-soft` |
| Действия строки | два зарезервированных слота по 28 px («Фокус», «Удалить»), видны при наведении/фокусе/выборе. У защищённых объектов (дрон, земля) слот «Удалить» пустой — «Фокус» не сдвигается |
| Раскрывающиеся строки | нативные `details` > `summary.pk-row` (иконка · название + подпись · счётчик · шеврон); закрытое содержимое скрыто; выбор полигона только меняет ожидающий шаблон, добавляет отдельная кнопка |
| Инспектор | `.pk-field` (подпись сверху 12/600, контрол 36 px), режимы трансформации — `.pk-seg`, одна primary «Применить», остальные кнопки secondary |
| Шрифт | 12 — подписи и подсказки; 13 — текст и контролы; 15 — заголовок панели; 17 — заголовок инспектора |
| Радиусы | 8 — контролы; 12 — контейнеры; 6 — внутренние элементы строк |
| Цвет | оранжевый — главное действие и «выбрано»; остальное нейтральное; вторичный текст ≥ 4.5:1 в обеих темах; оси X/Y/Z различаются буквами, а не цветом |
| Фокус и движение | видимый `:focus-visible`; переходы 120мс только цветом; отключаются при `prefers-reduced-motion` |

Проверка в браузере: у видимых элементов панели должны остаться радиусы {6, 8, 12}, размеры шрифта {12, 13, 15, 17} и ни одного текста с контрастом < 4.5:1, в обеих темах и на обеих вкладках.
