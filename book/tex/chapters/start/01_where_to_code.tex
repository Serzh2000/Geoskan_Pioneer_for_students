\section{Подготовка: где писать и запускать код}
\label{sec:start}

\begin{infobox}[Цели главы]
\begin{itemize}
    \item Понять, чем отличаются запуск в симуляторе и на настоящем дроне и чем различаются два дрона курса: Пионер Базовый и Пионер Мини~2.
    \item Найти в симуляторе редактор, выбор модели и языка, кнопки запуска и терминал.
    \item Запустить первую программу и увидеть её вывод.

\end{itemize}

\subsection{Два дрона и два способа запуска}

В курсе два дрона. \textbf{Пионер Базовый} программируется на Lua (программа загружается в автопилот) и на Python (программа работает на вашем компьютере). \textbf{Пионер Мини~2} Lua не знает: его программы написаны на Python и выполняются на самом дроне, а блоки Pioneer Bricks собирают такую же Python-программу. Для каждого дрона есть два «исполнителя»: симулятор и настоящий аппарат.

Код в обоих случаях один и тот же: симулятор воспроизводит официальный API автопилота (\texttt{ap}, \texttt{Ev}, \texttt{Timer}, \texttt{Ledbar}, \texttt{Sensors}), библиотеку \texttt{pioneer\_sdk} для Базового и \texttt{pioneer\_sdk2} с \texttt{pioneer\_rknn} для Мини~2. Поэтому в курсе мы сначала отлаживаем программу в симуляторе, а на дрон переносим уже проверенную. Отличия симулятора от железа (упрощённая нейросеть, часть методов \texttt{pioneer\_sdk2}) названы в соответствующих главах.

\begin{rulebox}[Сначала симулятор]
Любая новая программа запускается сначала в симуляторе. На настоящем дроне запускается только программа, которая в симуляторе взлетела, выполнила задание и села.
\end{rulebox}
