\subsection{Циклы}

Три вида повторения: числовой \verb|for| (счётчик от начала до конца включительно, с шагом), \verb|while| (пока условие истинно) и \verb|repeat ... until| (тело выполняется хотя бы один раз). Для таблиц есть \verb|for ... in ipairs(a)| и \verb|for ... in pairs(t)|.

Границы \verb|for i = 1, 10| включительны: \verb|i| принимает значения от 1 до 10. Необязательное третье число --- шаг: \verb|for i = 10, 0, -2| считает вниз через одно значение. \paragraph{Что происходит.}
\begin{itemize}
    \item \verb|ipairs| перебирает массив по порядку и останавливается на первом «пропуске» (\verb|nil|); \verb|pairs| перебирает все ключи словаря, порядок не гарантирован.
    \item \verb|break| прерывает цикл. Оператора \verb|continue| в Lua нет --- вместо него условие внутри тела.
\end{itemize}

\begin{warnbox}[Вечный цикл останавливает дрон]
Цикл \verb|while true do ... end| без выхода никогда не вернёт управление автопилоту: события перестанут приходить, таймеры --- срабатывать. Повторяющиеся действия на дроне делают таймером \verb|Timer.new| (глава~\ref{sec:leds}), а не бесконечным циклом. Программу с \verb|while true do| симулятор не запустит: уведомление «Запуск остановлен» объяснит почему. Другие вечные циклы (например, \verb|while x > 0| с забытым изменением \verb|x|) заранее не распознаются --- следите за условием выхода сами.
\end{warnbox}
